# Security policy

pii-gate is a guard rail. If you find a way to get personal data or secrets past it (a detector
bypass, a tamper-rule gap, a hook-protocol edge case that fails open), please report it privately:
open a [GitHub security advisory](https://github.com/sdursun1979/pii-gate/security/advisories/new)
on this repository. Please include a **synthetic** reproduction, never real data.

You will get an acknowledgement within a week. Fixes ship as a patch release with a changelog entry
that credits you, if you wish.

Supported: the latest minor release.
